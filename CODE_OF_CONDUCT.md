# Code of conduct

This project is a permissioned community beta. Participation is invited. Public launch is disabled.

## Expected behaviour

Be respectful. Critique the change, not the person. Do not harass, threaten, or publish someone else's private information.

## Roles

The five roles are functions: product/application, chain/security, media/provider agents, deployment/on-call, and trust/safety. No person is assigned here.

## Reports

Security reports follow `SECURITY.md`. Other conduct reports go to the repository owner in private. This file does not name a person.
