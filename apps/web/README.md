# apps/web

Scaffolding for the viewer and operator UI. The selected client family is React 19.3.1 and TypeScript 7.0.2. Those pins are in `package.json`.

This directory does not implement login, playback, uploads, or the operator dashboard. Goal 20 is the viewer. Goal 21 is creator publishing. Goal 24 is the operator dashboard.

`npm test` in this package checks the React pin. It does not verify a user interface.
