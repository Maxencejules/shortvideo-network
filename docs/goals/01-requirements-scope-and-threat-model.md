3. Record unresolved decisions about custody/recovery, operator admission, moderation/removal, retention,

4. Threat-model hostile uploads, unauthorized transactions, compromised keys, dishonest providers/auditors,
    unavailable replicas, chain stalls, stale gateways, abusive content and supply-chain attacks. Assign a
    mitigation, a test and a residual limitation to each. Include the distinction between an independent process
    and an independent operator.
5. Create docs/progress.md for all 30 goals. Define evidence statuses and dependencies, and identify tests
    needing cloud commands, a fuller Linux test runner, or independent machines. Do not promise dates,
    token totals, market adoption or production security.
