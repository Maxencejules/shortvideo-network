# packages/protocol

Handwritten loaders for the frozen off-chain schemas in `docs/protocol/schemas`. Manifests and signed-record types are those schema files. This package does not redefine them.

Generated protobuf stubs are not stored here. They are generated into `proto/` from `docs/protocol/proto`. Protocol v0 is frozen for this goal. An incompatible schema change needs a recorded decision.

The project licence split is not applied to this package. DEC-006 says Goal 03 records dependency licences and does not treat the split as an applied licence.
